# QuickBite Drive-Through Restaurant

## Run the project

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:
http://localhost:5173

## Build for deployment

```bash
npm run build
```

The production files will be created in `dist/`.

## Features
- Responsive menu
- Search and category filtering
- Food customization
- Shopping cart
- Quantity controls
- Dynamic subtotal/tax/total
- Drive-through pickup slots
- Customer checkout
- Order confirmation/progress
- Dark/light mode
